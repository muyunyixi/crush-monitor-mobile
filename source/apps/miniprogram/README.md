# 好感监控器小程序 · 正式版候选源码

此目录从已真机验证截图 OCR 的 v0.4.2（`0509b03`）继续开发。**当前代码仍需微信开发者工具编译及 iOS、Android、vivo 真机验收，尚未发布为最终版。**

## 当前已接入

- 聊天对象列表、显式示例对象、新建对象命名、逐对象草稿、本机 v0.4.2 数据迁移（保留旧存储键）、左右消息气泡及编辑／删除。明确身份的粘贴内容失焦后自动归档；OCR 草稿保持待校对状态。
- 最多四张截图沿原异步 OCR 上传；任务编号和短期查询凭据逐对象暂存，重新进入先查询未完成任务。单张失败保留其他已完成的文字，并显示失败原因；当前页面可重试尚未上传成功或明确失败的截图，查询中的任务继续查询以免重复上传。临时图片文件在小程序重启后可能失效，届时需重新选图。
- 逐条校对可调整发言人、时间、正文和消息边界；校对稿逐对象保存，确认后归档。对弱重合短句提供明确选择；未直接改写原始 OCR 文字时保留逐图来源，撤销只回退最近一张图对应的导入批次。若直接编辑整段 OCR 原文，按一次整体导入归档。
- 小程序独立分析接口、消息 ID 和 revision 结果检查，概览和逐句标签绑定原消息。可选最近 20／50／120 条或指定起止序号，一次不超过 120 条及 24000 字；所选范围逐对象保存。历史编辑和关系变更会阻止复用过期逐句结果，重新分析会提示额度影响。
- 点概览或逐句结果查看依据，定位原句后可返回进入详情之前的聊天位置。此交互还需真机验收。
- 14 种本地彩蛋，以及共同短语回声、“有后文”和话题回返候选；优先显示一个提示，其余集中查看证据；“有后文”由用户确认关联。关闭彩蛋与减少动效均有独立设置。
- 标准和兼容两种 Canvas 测字路径、范围选择、预览及相册保存入口。

## 与共享 Worker 配套

前端固定访问 `https://crush-monitor-mobile-api.muyunyixi.cloud`。源码在本仓库 `source/worker`，新版本使用 `/api/mini/analyze` 和经微信身份验证的 `/api/mini/quota`；OCR 任务查询增加临时凭据。旧 v0.4.2 上传未传 `taskVersion=2` 时保留旧查询协议。新接口需先发布 Worker 才能用于真机分析。不得把 `WECHAT_APP_SECRET` 和 `TYPESAFE_API_KEY` 写入小程序。

## 上线前仍需完成

- 正式小程序分析额度、失败返还与重置时区定版；后端计次与任务幂等的安全复核。
- OCR 逐条校对、重合决策、逐图撤销和失败截图重试需微信开发者工具及真机验证。
- 长图标准／兼容方案在真机的字体测量及超长画布验收；全量屏幕宽度、系统大字、证据返回锚点验收。
- 彩蛋规则还需更多真实脱敏样例检验误触发；“有后文”候选需核对中文表述和动效表现。可选的后续轻交互未视为当前已验收功能。
- 发布前回归原 v0.4.2 OCR，以及网页分析、健康与额度接口。旧客户端和新客户端不得同时部署到不兼容的 Worker 版本。

本机记录不会自动云备份。主动识字的截图经 Worker 转交微信 OCR；主动分析的聊天文本经 Worker 转交模型服务。分析数字表示聊天文本信号，不代表真实感情概率。

小程序分析额度由 Worker 环境变量 `MINI_ANALYSIS_DAILY_LIMIT` 控制，未配置时新分析接口返回 503。该数值、失败返还和重置时区仍需按总规范定版；不要把网页的每日十批次自动当作小程序的运营承诺。

本目录是[总仓库](../../../README.md)内的原生小程序项目，微信开发者工具可直接导入本目录；共享 Worker 只由总仓库部署。
