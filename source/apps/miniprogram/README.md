# 好感监控器小程序 · 正式版开发中

此目录从已真机验证截图 OCR 的 v0.4.2（`0509b03`）继续开发。**当前代码仍需微信开发者工具编译及 iOS、Android、vivo 真机验收，尚未发布为最终版。**

## 当前已接入

- 聊天对象列表、逐对象草稿、本机 v0.4.2 数据迁移（保留旧存储键）、左右消息气泡及编辑／删除。
- 最多四张截图沿原异步 OCR 上传；任务编号和短期查询凭据逐对象暂存，重新进入先查询未完成任务。单张失败保留其他已完成的文字。
- 小程序独立分析接口、消息 ID 和 revision 结果检查，概览和逐句标签绑定原消息。分析使用当前对象最近 120 条且不超过 24000 字。
- 14 种本地彩蛋的初版判定及证据入口，普通词语反例得到基本抑制。关闭彩蛋可隐藏标签。
- 标准和兼容两种 Canvas 测字路径、范围选择、预览及相册保存入口。

## 与共享 Worker 配套

前端固定访问 `https://crush-monitor-mobile-api.muyunyixi.cloud`。源码在本仓库 `source/worker`，新增 `/api/mini/analyze` 并为新客户端的 OCR 任务查询增加临时凭据；旧 v0.4.2 上传未传 `taskVersion=2` 时保留旧查询协议。新接口需先发布 Worker 才能用于真机分析。不得把 `WECHAT_APP_SECRET` 和 `TYPESAFE_API_KEY` 写入小程序。

## 上线前仍需完成

- 正式小程序分析额度、失败返还与重置时区定版；后端计次与任务幂等的安全复核。
- OCR 校对的消息边界、疑似重叠选择、失败项重试和跨图批次撤销；目前主要通过可编辑文字区校对。
- 长图标准／兼容方案在真机的字体测量及超长画布验收；全量屏幕宽度、系统大字、证据返回锚点验收。
- 彩蛋规则的完整正反例、去重与展示预算；“未来便签”后文配对和进一步轻交互。
- 发布前回归原 v0.4.2 OCR，以及网页分析、健康与额度接口。旧客户端和新客户端不得同时部署到不兼容的 Worker 版本。

本机记录不会自动云备份。主动识字的截图经 Worker 转交微信 OCR；主动分析的聊天文本经 Worker 转交模型服务。分析数字表示聊天文本信号，不代表真实感情概率。

小程序分析额度由 Worker 环境变量 `MINI_ANALYSIS_DAILY_LIMIT` 控制，未配置时新分析接口返回 503。该数值、失败返还和重置时区仍需按总规范定版；不要把网页的每日十批次自动当作小程序的运营承诺。

本目录是[总仓库](../../../README.md)内的原生小程序项目，微信开发者工具可直接导入本目录；共享 Worker 只由总仓库部署。
